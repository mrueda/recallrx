# Help with the App

## I Cannot Find a Recall

Check the country first. A notice from Spain will not appear while Portugal or
France is selected.

Next, clear the year and date filters and try a shorter search. For example,
search for the medicine name without its strength or package size. For a lot or
product code, check every letter and number.

If there is still no match, search the medicines authority's website. RecallRx
may not yet include a new notice, and older notices may not be available from
every source.

## The Data Looks Out of Date

Check the update status at the top of the app. It shows the exact time of the
latest data update for the selected country and warns when that update is more
than 48 hours old.

Reload the page to make sure your browser is not showing an older copy. If the
warning remains, use the official authority links until the next RecallRx update
has completed.

## Only One Country Appears

Reload the live app and use the country buttons in the top navigation. If an old
saved page still shows only Spain, open the current address directly:

## The Search Page Repeats Inside Itself

Open the direct app link above instead of an old bookmarked documentation or
embedded-app address. Then replace the old bookmark. Reloading the direct link
usually removes a cached copy of the earlier layout.

## A Label Is Unclear

Hover over the label with a mouse or move keyboard focus to it. Labels such as
`Completo`, `Revisar`, and `Sin CIP` include a short explanation. The
[Use the App](./quickstart.md) guide also explains the colors and update status.

## I Still Need Help

Report a reproducible problem in the
[GitHub issue tracker](https://github.com/mrueda/recallrx/issues). Include the
country, search term, filters, and browser you used. Do not include personal or
private health information.
