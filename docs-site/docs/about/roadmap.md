# Roadmap

## Available Now

- Recall notices from AEMPS in Spain, INFARMED in Portugal, and ANSM in France.
- Search by medicine, product code, lot, alert number, year, and date range.
- Direct links to official pages and PDFs when available.
- Daily updates through GitHub Actions.
- Downloadable, country-specific JSON data.
- A collector structure that supports additional countries.

## Next Priorities

- Check and improve the coverage of older notices.
- Use CIMA to add useful Spanish medicine details.
- Decode GS1 DataMatrix codes and use them to look up Spanish CN product codes.
- Assess reliable public sources for more countries, including Andorra.

## Possible Later Work

- Data-quality reports for each country.
- Links between equivalent product codes in different countries.
- Clearer maintainer reports when a source page cannot be read completely.
- Additional authorities such as the FDA, MHRA, Health Canada, and TGA.

Countries will be added only when RecallRx can collect their notices
reliably and link each record to an official source.
